# Flowshopper

## 1. Presentation
Flowshopper is the island's online grocery store. This monorepo contains:
- `web/` : site, back-office and server (Web team)
- `reco/` : recommendation system and API (AI team)
- `simulator/` : traffic simulator
- `mocks/` : mock of each team for the other
- `docs/` : Web team documentation, `CONTRACT.md`, `DECISIONS.md`
